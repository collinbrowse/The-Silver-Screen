# Epic: Advanced Search Tab

Take the Search tab to the next level with segmented search across Movies, TV, and People. All new work is SwiftUI.

| # | Story | Done |
| --- | --- | --- |
| 1 | Add a segmented controller at the top of the screen when you click on Search: Movies, TV, and Person. | [ ] |
| 2 | If you are on the Movies tab, you see a list of popular movies (like before). If you are on TV, you see a list of popular TV. If you are on People, you see a list of popular people. | [ ] |
| 3 | When you search, you make a call to the API to search for whatever state you are in on the segmented controller. On Movies, you search movies; on TV, you search TV; on People, you search people. | [ ] |
| 4 | These are all paginated lists, so handle pagination accordingly. | [ ] |
| 5 | TV UI: cell shows main image, TV name, genres, and first air date. | [ ] |
| 6 | People UI: cell shows profile image, name, and known-for department. Clicking a cell takes you to that person. | [ ] |
